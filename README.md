## 🏆 Featured Projects

### 💻 1. 長崎大学オープンキャンパス Web アプリ
> **大学公式システムとして有志4名で開発・運営している案内Webアプリ**
> - **役割:** 企画提案・フロントエンド開発（有志4名）
> - **技術:** React / Next.js / TypeScript / Git / GitHub

従来のオープンキャンパスでは紙の案内パンフレットが使われていましたが、スペースの都合上、各研究室の展示の魅力が高校生に伝わりきらない課題がありました。また、直前まで何度も変更される展示データをその都度手作業で修正する、運営スタッフの膨大な作業手間も大きな問題でした。

そこで、興味のある分類タグ（AIやロボット等）をタップするだけで展示場所が連動してすぐに見つかる直感的なWebアプリを開発しました。さらに、専門知識のないスタッフでもExcelの展示データを貼り付けるだけで一瞬で情報を更新できる簡易管理システムも構築しました。
活動の継続性を高めるため、写真担当の1年生と連携して当日の撮影計画や特設サイトの準備を進め、引き継ぎ体制も構築しています。

* **成果:** 担当教授陣へのプレゼンを経て「広報委員会0期生」として公式認定を獲得。当日の様子をまとめた特設サイトが大学公式ホームページに採用・掲載されました。

### 🎨 2. フィッシング詐欺防止 3DCGアニメーション
> **警察庁主催コンテストにて全国最優秀賞（サイバー警察局長賞）を受賞した啓発アニメーション**
> - **役割:** ディレクター兼メインクリエイター（有志3名）
> - **技術:** Blender / Adobe Premiere Pro / Git

若い世代に向けたフィッシング詐欺の注意喚起を目的とした3Dアニメーション（40秒）の制作です。従来の防犯ポスター等の啓発活動は堅苦しく、若者に興味を持ってもらえないこと、また映像内の詐欺画面にリアリティがないと実際の被害をイメージしにくいという課題がありました。

そこで、親しみやすい3Dの動物キャラクターを主人公としつつ、アニメーション内に登場する偽サイトは実際のWeb開発技術を用いて本物そっくりに構築し、リアルな怖さと警戒心が伝わる演出を徹底しました。チーム内ではディレクターとして全体のストーリー設計とCG制作を主導し、背景小物の配置や音響は他メンバーと役割分担を行って効率的な共同制作フローを確立しました。

* **成果:** 全国約50作品の中から1位となる「最優秀賞（サイバー警察局長賞）」を受賞。

### 🔬 3. VR酔い低減・適応型動的3D映像合成システム (修士研究)
> **最新AIを活用したVR酔い防止と視覚的快適性の科学的実証**
> - **役割:** 研究者（個人研究）
> - **技術:** Python / PyTorch / OpenCV / Unity / 3Dプリンター

VRゴーグルを着用した際に発生する頭痛や吐き気（VR酔い）を防止するためのAI映像処理システムの研究です。複数のカメラ映像をつなぎ合わせて3D映像を作る際、カメラ同士のつなぎ目のズレや映像の揺れが、激しいVR酔いを引き起こす原因となっていました。

そこで、撮影環境の変化をAIで自動検知し、カメラのつなぎ目（境界線）を「人がいない場所」へリアルタイムに自動回避させるアルゴリズムを開発しました。また、物理的な撮影時のミリ単位のズレを防ぐため、3Dプリンターで独自のカメラ固定器具を設計・自作しました。

* **成果:** 被験者実験を行い、専門的な酔いの評価基準において、酔いの低減効果を客観的・科学的データによって実証。
* **関連リポジトリ:**
  - 🐙 [360-video-synthesis-v2](https://github.com/yoshiototora/360-video-synthesis-v2) : 修士研究メインコード（順次構築予定）
  - 🐍 [vr-ssq-evaluation](https://github.com/yoshiototora/vr-ssq-evaluation) : 被験者実験（SSQ）における酔いの評価・検証用プログラム
  - 💻 [Quest3S_VideoTest](https://github.com/yoshiototora/Quest3S_VideoTest) : Meta Quest 3S デバイスでの検証用（動的表示テストなど）プログラム

### 💻 4. 簡易360°全周囲3D映像のシームレス合成システム (卒業研究)
> **安価なカメラ3台を用いて低コストで自然な立体VR映像を作り出す映像処理システム**
> - **役割:** 研究者（個人研究）
> - **技術:** Python / PyTorch / OpenCV / 3Dプリンター

特殊な高額カメラを使わずに、市販の安価なカメラ3台で自然な立体VR映像を作り出す映像処理システムの研究です。安価な構成では、カメラ同士の見え方のズレ（視差）によって、つなぎ目で人物の形状が不自然に歪んでしまう課題がありました。

そこで、最新のAI技術を用いて「人物」と「背景」を自動で別々に切り分け、人物の形を綺麗に保ったまま映像のズレを補正する画像処理プログラムを構築しました。また、3Dプリンターで3台のカメラを正確に固定する土台も手作りしました。

* **成果:** 不快感のない自然な立体映像の作成に成功し、現在の修士研究の強固な土台となっています。
- **関連リポジトリ:**
  - 🐙 [360-video-synthesis-v1](https://github.com/yoshiototora/360-video-synthesis-v1) : 卒業研究のメインコード

### 📱 5. HabitSpark (iOSアプリ)
> **「失敗から学ぶ」ことで挫折を防ぐ、個人開発の習慣化支援アプリ（App Store配信中）**
> - **役割:** 個人開発（企画・UI設計・データベース設計・Swift実装・公開・アップデート）
> - **技術:** Swift / SwiftUI / SwiftData / Git

既存の多くの習慣化アプリは「毎日完璧に続けること」を前提としており、一度サボると挫折しやすい点や、目標が大きすぎて何から行動に移せばよいか分かりにくい課題がありました。

そこで、目標を「月・週・日次」に段階的に分解できる設計と、失敗した日は独自の振り返り（KPT法）を行い、改善策（Try）がそのまま翌日のタスクになる「挫折せず自然に改善サイクルが回る」仕組みを構築しました。
App Storeでのユーザーレビュー（「出来なかったタスクを翌日に引き継ぎたい」）を契機に、単に翌日にコピーするのではなく、3日連続で未完了のタスクは自動的に「課題（Problem）」に差し戻し、目標設定の難易度自体を見直せる独自のUXを実装しました。

* **成果:** 既存ユーザーのこれまでの大切な記録を1件も壊すことなく、安全にデータベース構造の移行（マイグレーション）を完遂しました。
- **関連リンク:**
  - 📱 [App Store（配信ページ）](https://apps.apple.com/jp/app/habitspark/id6762178668)
  - 🐙 [GoalTracker (HabitSparkソースコード)](https://github.com/yoshiototora/GoalTracker)
