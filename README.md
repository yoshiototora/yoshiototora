## 研究・制作

### 360°3D映像の研究

3台の360°カメラの映像から、VRで視聴できる立体映像を生成しています。
つなぎ目で人物の形が崩れる問題に対し、AIによる深度推定で前景と背景を分けて合成する手法を研究しています。カメラの固定器具も3Dプリンターで設計・制作しました。

評価実験では、つなぎ目の見え方と映像の安定性が改善しました。視差量も比較し、今回の実験では55mm相当の条件が65mm相当よりVR酔いを抑える結果になりました。

`Python / PyTorch / OpenCV / Depth Anything V2`

[映像合成 v2](https://github.com/yoshiototora/360-video-synthesis-v2) · [卒業研究 v1](https://github.com/yoshiototora/360-video-synthesis-v1) · [SSQ分析](https://github.com/yoshiototora/vr-ssq-evaluation) · [Questでの検証](https://github.com/yoshiototora/Quest3S_VideoTest)

### HabitSpark

目標を月・週・日に分けて管理する習慣化アプリです。企画・UI設計・実装・公開を個人で担当しています。

KPTによる振り返りと、改善策を翌日のタスクに反映する機能を実装しました。レビューを受けて未完了タスクの引き継ぎ機能も追加し、3日連続で未完了のタスクはProblemに戻して見直せる設計にしています。

`Swift / SwiftUI / SwiftData`

[App Store](https://apps.apple.com/jp/app/habitspark/id6762178668) · [コード](https://github.com/yoshiototora/GoalTracker)

### オープンキャンパスの案内Webアプリ

大学の有志4人で開発しました。企画提案とフロントエンドを担当しています。

AIやロボットなどのタグから、展示とその場所を探せる案内アプリです。運営側には、Excelの展示データを貼り付けて情報を更新できる管理機能を用意しました。

活動は「広報委員会0期生」として認定され、当日の様子をまとめた特設サイトも大学公式ホームページに掲載されました。

`React / Next.js / TypeScript`

### フィッシング詐欺の啓発アニメーション

有志3人で制作し、ストーリーと3DCG制作を中心に担当しました。
釣りをする猫を詐欺師、宅配を待つ犬を被害者に見立て、フィッシング詐欺の手口と注意点を伝える動画です。作中の偽サイトは、実際にWebページを制作して再現しました。

`Blender / Adobe Premiere Pro`

### 生マッコリの販路開拓インターン

雲南市のMisfits Japanで、生マッコリ「OMONA YANGJO」の営業を約1か月経験しました。

店舗の料理に合わせた提案や、返信しやすい文章に見直し、DMの返信率を1%未満から約5%に改善しました。AIを活用した店舗調査・文章作成・重複確認の手順も整備しました。

5,001店舗にDMを送信し、225店舗から返信、59件のサンプル発送につながりました。インターン後の進展も含めて、6店舗との契約に至りました。
